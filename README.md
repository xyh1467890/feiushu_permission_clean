## 整体背景
在数据治理场景中，「原始样张」与「需要清洁的样张」之间存在大量数据表和权限配置，人工核查工作量大、容易遗漏。故在这里做一个自动化，本项目是基于 LangGraph + LLM 构建本地 Agent，自动检查「需要清洁的样张」中的**数据表结构**和**高级权限配置**是否与「原始样张」完全一致，如存在任何不一致之处，明确标注为异常。

## 核心功能
- ✅ **表结构对比**：自动检查表格、字段、字段类型等是否一致
- ✅ **权限配置对比**：自动检查角色、表权限、字段权限等是否一致
- ✅ **代码快速对比**：先进行代码层面的标准化对比，完全一致时直接跳过 AI 调用，提高效率
- ✅ **AI 深度分析**：如果代码对比发现不一致，使用 AI 进行详细分析，给出清晰的差异说明
- ✅ **并发处理**：支持同时处理多个任务，提高效率

### src/ 
#### 1. config.py - 配置文件
这是项目的"控制面板"，包含所有需要调整的设置：
- 文件路径：输入输出文件在哪里
- 并发数：同时处理多少个任务（建议 20-50）
- LLM 配置：调用哪个 AI 模型，用什么 API

#### 2. feishu_api.py - 飞书 API 工具
这是专门负责和飞书对接的模块：
- **获取飞书访问权限**：只使用 user_access_token
- 解析飞书链接
- 提取数据表的信息（有哪些表、有哪些字段、字段类型是什么）
- 提取高级权限配置（角色、权限规则等）

#### 3. evaluation_nodes.py - 工作流节点
这是工作流中的所有核心步骤：
- **parse_bitable_urls**：把飞书链接转成数据表的元数据和权限配置
- **compare_tables**：代码快速对比，先做标准化（移除不稳定字段、排序），然后对比是否一致
- **analyze_table_with_llm**：用 AI 对比两个表结构是否一致
- **analyze_permission_with_llm**：用 AI 对比两个权限配置是否一致
- **combine_results**：合并表结构和权限的结果，判断最终结果

#### 4. evaluator.py - 主程序（入口文件）
这是你要运行的文件，它负责：
- 读取输入的 CSV 文件
- 组织工作流（解析链接 → 代码对比 → AI 分析 → 合并结果）
- 把结果保存到输出文件
- 显示处理进度和统计信息

#### 5. prompts.py - AI 提示词
这里放的是给 AI 看的指令，分为两部分：
- **表结构评测提示词**：告诉 AI 如何对比数据表
- **权限配置评测提示词**：告诉 AI 如何对比高级权限

### data/ - 数据文件目录
#### 1. evaluation_input.csv - 输入数据
包含你要评测的飞书链接，格式是：
- id：序号
- 原始样张：参考的标准链接
- 需要清洁的样张：待对比的链接

#### 2. evaluation_result.csv - 输出结果
评测完成后的结果，包含：
- 解析后的两个数据表元数据
- 解析后的两个高级权限配置
- 评测结果（正确/异常/处理失败）
- 原因说明



## 使用方法
1. 准备 `data/evaluation_input.csv`，填入要对比的飞书链接
2. 配置 `.env` 文件（参考 `.env.example`）
3. 运行 `python src/evaluator.py`
4. 查看输出结果 `data/evaluation_result.csv`
